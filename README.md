# По плану — месячный бюджет

Локальное учебное приложение: Java 21+ и HTML/CSS/JavaScript, без библиотек и базы данных.

## Запуск
Из папки проекта:

```sh
java --add-modules jdk.httpserver src/BudgetApp.java
```

Открой http://localhost:8080. Остановка: Ctrl+C.

В IntelliJ IDEA открой папку проекта, выбери JDK 21 или новее, открой src/BudgetApp.java и нажми зелёный треугольник рядом с main. Рабочая директория — корень проекта, содержащий public.

## Формулы
Все суммы на сервере считаются в копейках. Доход = две выплаты. Расходы = жильё + продукты + транспорт + прочее. Отдельно задаётся резерв. Остаток цели = max(0, цель − накоплено). Ежемесячное накопление = остаток / число месяцев, округлённое вверх до копейки. Свободные траты = доход − расходы − резерв − накопление.

Отчисления с зарплат пропорциональны их суммам; остаток округления приходится на вторую выплату. При дефиците показан минимальный достижимый срок, если доступный остаток положительный. Резерв не засчитывается в цель. Нет процентов, инфляции и календаря платежей. Дневной ориентир использует среднюю длительность месяца 30,44 дня.

Примеры вымышленные. Данные сохраняются в localStorage только по кнопке. Сервер слушает только локальный интерфейс. Публичная публикация не настроена.
